# Design — Add Product Standards (pizdato-net)

## Approach

Add a single root-level `product-standards.md` following the team template
`projects/product-standards.template.md`. Content is the pizdato-net entry already agreed
in the team's `projects/product-standards.md` — kept in sync as the single source of truth.

## Layout

- Root: `product-standards.md` — the canonical per-project standard (English).
- Structure mirrors the template: mandatory core (4 axes) + "specific to project" +
  owner list.

## Language

English, per the "GitHub content is English" rule. The team's vault copy stays Russian.

## Risk / notes

- This is a documentation-only change; no code, no behavior change.
- Sync responsibility: the repo `product-standards.md` and team `projects/product-standards.md`
  should match; flag drift in review.
