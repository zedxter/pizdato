## Context

После голосования на pizdato.net показывается SharePanel с кнопками:
- Поделиться цитатой (копировать текст)
- Скачать бейдж (canvas 720×280)
- Поделиться в Telegram / VK
- Нативный шаринг

Бейдж содержит: выбор пользователя, проценты голосов, мудрость дня. Формат — горизонтальный 720×280.

## Goals

1. **Замкнуть виральный цикл**: человек скачал бейдж → поделился → новые люди видят `pizdato.net` → переходят на сайт
2. **Получить данные**: сколько скачиваний, сколько шарингов — действенные метрики
3. **Сделать бейдж удобным для сторис**: вертикальный формат под Telegram/Instagram

## Decisions

### 1. Подпись `pizdato.net`

- Разместить в правом нижнем углу, мелким шрифтом (10px), полупрозрачным (#9aab9e)
- Не кликабельно (это картинка)
- Проверить, что не перекрывает существующие элементы

### 2. Трекинг

- Использовать `navigator.sendBeacon()` — не блокирует UI, не требует библиотек
- Куда шлём: `/_/event?type=badge_download` (через существующий nginx, который логирует все запросы)
- События: `badge_download` (скачал), `badge_share_stories` (скачал для сторис)
- В дайджесте (6:00) выводить «скачиваний бейджа: N»

### 3. Вертикальный формат

- Размер: 540×960 (стандарт Telegram-сторис 9:16)
- Расположение: то же содержимое, но адаптированное под вертикаль
- Цитата — в центре, проценты — снизу, подпись — внизу
- Отдельная функция `renderVerticalBadgeCanvas()` в `badge.ts`

### 4. Кнопка в SharePanel

- Иконка: «Сторис» (или использовать Telegram-иконку с подписью)
- Текст: «Сторис»
- Вызывает скачивание вертикального бейджа
