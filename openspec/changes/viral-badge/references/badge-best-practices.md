## Где люди используют бейджи

| Площадка | Формат | Размер | Особенности |
|----------|--------|--------|-------------|
| **GitHub** | Horizontal | ~400×120 | Профиль README, markdown-совместимые |
| **Stack Overflow** | Circular | 32×32 | Аватарка, значки достижений |
| **Strava** | Square | 400×400 | Спортивные достижения, соцсети |
| **Duolingo** | Horizontal | 320×160 | Прогресс, удержание streak |
| **Instagram Stories** | Vertical 9:16 | 540×960 | Основной формат для сторис |
| **Telegram Stories** | Vertical 9:16 | 540×960 | Активно растёт, поддерживается нативно |
| **Email signatures** | Horizontal | 600×200 | Часто игнорируется, нужен яркий дизайн |
| **Twitter/X** | Square/Horizontal | 800×400 | Слабая поддержка вложений, лучше ссылка |

## Что делает бейдж виральным

1. **Понятность за секунду** — пользователь должен сразу понять, что это
2. **Эмоциональный выбор** — "Я за пиздато!" — это позиция, а не просто цифры
3. **Метрика для сравнения** — проценты дают контекст (67% vs 33%)
4. **Водяной знак** — pizdato.net внизу, чтобы распространялся бренд
5. **Формат под площадку** — горизонтальный для TG/email, вертикальный для сторис

## Выводы для pizdato.net

- **Горизонтальный 720×280** — оптимален для подписей, форумов, TG-каналов
- **Вертикальный 540×960** — обязателен для сторис (TG, Instagram)
- **Подпись pizdato.net** — замкнутый виральный цикл
- **Трекер скачиваний** — действенная метрика (build-measure-learn)
