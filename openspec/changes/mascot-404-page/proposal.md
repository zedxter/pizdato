## Why

Сайту не хватает «лица». Есть логотип, есть контент, но нет персонажа, который бы запоминался и создавал эмоциональную связь. Маскот — стандартный приём для проектов с характером: Duolingo (сова), GitHub (mona), Mailchimp (Фредди). Для pizdato.net с его дерзким тоном и матерной лексикой персонаж особенно органичен.

404 страница сейчас — стандартный React fallback, не несёт пользы и не смешит. Это потерянный трафик и плохой сигнал для пользователя.

## What Changes

- **Маскот «дядя Вова»** — суровый, усатый мужик в ушанке, который как бы оценивает всё вокруг. Появляется на 404 странице с коронной фразой.
- **404 страница** — кастомная страница с маскотом, случайной цитатой из `quotes.ts` и кнопками: «На главную», «Голосовать», счётчик статистики.
- **Favicon** — обновить на иконку маскота (лицо) или комбинацию с буквой П.
- **Telegram-канал аватарка** — вариант 7 (pizdato: с двоеточием) или лицо маскота.

## Non-Goals

- Не меняем существующие страницы (главная, статьи, эссе, лента, FAQ).
- Не добавляем маскота в статьи или на главную — только 404 + опционально фавикон.
- Не переписываем контент 404-страницы кроме дизайна и маскота.

## Capabilities

### New

- `mascot-branding`: Определяет маскота «дядя Вова», его визуальный стиль, варианты использования (404, favicon, TG-аватарка).

### Modified

- `seo-indexability`: 404 страница должна отдавать 404 HTTP-статус, но содержать полезный контент (навигация, статистика) для удержания пользователя.

## Impact

- `frontend/src/App.tsx` — добавить роут для 404 / кастомный fallback.
- `frontend/public/favicon.ico`, `favicon-32.png`, `favicon.png` — заменить на маскот.
- `frontend/public/` — добавить изображение маскота.
- `frontend/src/` — возможно новый компонент `Mascot.tsx` или `Mascot404.tsx`.
- Deploy: скопировать новые иконки + статику в `dist/` и `/var/www/pizdato/`.
