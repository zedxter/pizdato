## Context

См. proposal.md. Сайт pizdato.net — голосование «пиздато / хуёво» с матерным тоном, тёмным дизайном, двумя зелёно-красными полюсами. Маскот должен быть в этом же тоне: суровый, ироничный, «свой».

## Goals / Non-Goals

**Goals:**
- Создать маскота «дядя Вова» — усатый мужик в ушанке, оценивающий всё вокруг.
- Разработать 404 страницу, которая не разочаровывает, а развлекает.
- Обновить favicon и TG-аватарку опционально.

**Non-Goals:**
- Маскот не появляется на главной, в статьях, ленте, FAQ, эссе.
- Не меняем существующий дизайн страниц, не добавляем анимацию маскота.

## Decisions

### 1. Образ маскота
«Дядя Вова» — средних лет, усы, ушанка, свитер, хитрый взгляд. Стиль — минималистичная векторная иллюстрация, 2-3 цвета, без фона (PNG с прозрачностью). Варианты:
- Спокойный: руки скрещены, оценивающий взгляд.
- Весёлый: с чаем, подмигивает.

### 2. 404 страница — макет
```
┌──────────────────────────────┐
│         [лого pizdato]        │
│                               │
│       [маскот] 404            │
│    «Ты забрёл в хуёвый угол»  │
│                               │
│   [случайная цитата из базы]  │
│                               │
│  [На главную] [Голосовать]    │
│                               │
│    ← Всего голосов: 159      │
└──────────────────────────────┘
```

### 3. Favicon
Лицо маскота (упрощённое, 32×32) или буква П с расколом на зелёный/красный.

### 4. TG-аватарка
Вариант 7 (pizdato: с двоеточием) — он уже сгенерирован, строгий, с намёком на оценку.
