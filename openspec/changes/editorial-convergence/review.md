## Evaluation integrity

The fixtures and the rubrics were written by the same agent, so every fixture change made after seeing a result is recorded in that fixture's note:

- `nasa-quote-attributed-to-misha` was reworded so that Uncle Misha speaks the administrator's words himself (the earlier wording read as a faithful quotation of NASA's condition), and `voice` is accepted alongside `grounding`. It still counts as an objective fixture and the injected quote must be named.
- `circular-platitude` and `lottery-sold-as-life-hack` are reported as borderline (taste or irony) and do not count toward the bar; the lottery classification was made after its first misses.
- A proofreader example copied from `stickney-wrong-phrase-wife` was removed before the release run. Three held-out fixtures of the same class (a word used in a meaning it does not have) were written before that run and were never used to tune a rubric.
