# Morning publication

## ADDED Requirements

### Requirement: Lively restrained presentation
The host MUST decorate the morning attribution with one coffee emoji and the wish with one sparkle emoji. The generation prompt MUST request conversational, concrete wit and varied wishes. Raw generated fields MUST remain emoji-free. Existing word limits, no-promotion rules, scheduling and duplicate protection MUST remain in force.

#### Scenario: Render polished copy
- **GIVEN** valid wisdom and a witty wish
- **WHEN** the host renders the morning message
- **THEN** it adds the two decorative emojis without adding links, reaction prompts or other content
